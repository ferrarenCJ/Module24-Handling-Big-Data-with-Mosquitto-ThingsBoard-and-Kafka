# Mosquitto Coding Activities

## Overview

This folder contains MQTT and Mosquitto exercises completed during Module 24.

## Topics Covered

- MQTT Protocol
- Publish / Subscribe Messaging
- Mosquitto Broker
- Paho MQTT Client

## Activities

### Publisher

Generates telemetry data and publishes MQTT messages.

### Subscriber

Subscribes to MQTT topics and receives telemetry.

## Architecture

```text
Publisher
    ↓
Mosquitto Broker
    ↓
Subscriber
```
