# Question 1

## What is MQTT?

### Correct Answer

✅ MQTT is a protocol for handling sensor data.

### Explanation

MQTT stands for:

**Message Queuing Telemetry Transport**

It is a lightweight messaging protocol specifically designed for:

- IoT devices
- Telemetry systems
- Sensors
- Real-time streaming applications

MQTT can efficiently process data generated by millions of connected devices.

### Key Takeaway

MQTT is optimized for IoT and sensor communications.

---

# Question 2

## Which of the following methods is used by the MQTT broker?

### Correct Answer

✅ Publish and subscribe method

### Explanation

MQTT uses a Publish/Subscribe architecture.

Workflow:

```text
Publisher
     ↓
MQTT Broker
     ↓
Subscriber
```

Publishers send messages to topics.

Subscribers receive messages from topics.

The broker manages the routing of messages between the two.

### Key Takeaway

MQTT brokers rely on the Publish/Subscribe messaging pattern.

# Question 4

## Which Python library can be used to connect to the MQTT broker?

### Correct Answer

✅ Paho

### Explanation

The Eclipse Paho Python library provides MQTT client functionality.

Example:

```python
import paho.mqtt.client as mqtt

client = mqtt.Client()
client.connect("localhost", 1883)
```

Paho enables:

- Broker connections
- Publishing messages
- Subscribing to topics
- Event handling

### Key Takeaway

Paho is the standard Python MQTT client library.

# Question 5

## Which of the following Python statements can be used by a client to subscribe to a topic?

### Correct Answer

✅ client.subscribe(topic)

### Explanation

Subscribers use the subscribe() method to listen for messages.

Example:

```python
topic = "sensors/temperatures"

client.subscribe(topic)
```

The client will receive all future messages sent to that topic.

### Key Takeaway

Topic subscriptions are created using:

```python
client.subscribe(topic)
```

# Question 6

## What are brokers?

### Correct Answer

✅ Brokers are applications that enable devices, systems, and services to communicate with each other and exchange information.

### Explanation

A broker acts as an intermediary between publishers and subscribers.

Responsibilities include:

- Receiving messages
- Managing subscriptions
- Routing messages
- Delivering messages

Example:

```text
Temperature Sensor
         ↓
 Mosquitto Broker
      ↓     ↓
Dashboard Firebase
```

The broker allows systems to communicate without directly connecting to one another.

### Key Takeaway

A broker is the central communication hub in MQTT architecture.
